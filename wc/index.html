定了

先做：落地清单

给来加拿大的新人，留学生、工签、新移民、陪读家长都算，一套按各人情况走的行政清单：填几个日期，页面告诉你还剩几天、下一步做什么、官方大概要等多久、等不及的时候有什么常见做法。第一批三份：学签续签和被退回怎么重交；毕业后 180 天内的 PGWP；TRV 和 SIN 的更新顺序。学签续签这份先做到能真办事，另外两份先上基础版。之后按到期时间铺开：报税、驾照、医保、开户、手机、回国前。

我以前给自己做过回国清单和签证冲刺清单，单文件网页，能勾选、能存进度。这次是把它从「给我一个人」变成「用户自己填情况、自己走」，中间加一层 AI，只答核对过的内容。引擎和登录你已经有了，缺的是个案字段、倒计时、问一句、提醒、支付。

钱

清单免费看，免费的每天能问三句；付费的是存进度 + 到期提醒 + 更新推送 + 不限问，一年 C$19 到 29；清单包按场景卖 C$9；开户、手机、保险的新客联盟按成交。第一年目标：付费用户几百人，覆盖你我的时间。定价先这么定，跑一个月再改。

四周之内算不算成

三份清单上线；小红书三帖收藏合计过 500；打开清单的人过 300；付费或订阅提醒的过 50。四件成三件算成。不成就换第二个方向，引擎不扔。

不做什么

不做移民建议，不判断资格，不代办，只做信息和清单，因为收费给建议只有持牌顾问、律师、魁北克公证人能做。不存证件号，不存上传的原件。不做联动情报和城市活动那些。

技术任务书

用户会做的六件事

  1. 选场景：我是学签快到期 / 交了续签还没消息 / 刚毕业要办 PGWP / 要更新 TRV 和 SIN
  2. 填自己的情况：几个日期和几个状态，比如学签到期日、提交日、收没收到确认信、生物识别做没做。只填日期和选项，不填证件号
  3. 看倒计时：场景顶上三个数。距到期还有几天；交了之后按官方处理时间页面当天的数，预计还要等几天；如果已经过期，恢复身份的 90 天窗口还剩几天
  4. 走清单：步骤按填的情况重排，用不上的步骤收起来。每步有官方链接、材料、常见的坑，再加一层「常见做法」：什么时候用 IRCC 网页表单催、什么情况下找自己选区的 MP、GCMS notes 怎么申请。每条标来源和核对日期
  5. 问一句：页面里打「我 7 月 3 号交的，到现在没消息，怎么办」。AI 只在这个场景核对过的内容里找答案，固定回四段：你现在在哪一步 / 下一步 / 预计还要多久（哪来的数）/ 什么时候可以走网页表单或 MP。答不了就说答不了，给官方入口
  6. 收提醒和分享：到期前 60 天、30 天、7 天邮件；官方规则变了也推；分享出去是干净的一份

AI 这层的边界

规则怎么做
只引用，不发挥回答只能用这个场景里的 step 和 tip，加用户填的字段和处理时间快照。每段带内容编号，改内容就等于改答案
不判断资格「我能不能办」「我算不算符合」一律不答，回官方的判断工具链接
固定四段在哪一步 / 下一步 / 预计多久（来源和日期）/ 等不及怎么办。不出现「你应该」，用「官方要求」「常见做法」
上传读完即删信件截图只为读出三样：信的类型、日期、状态。抽出来给用户确认，原件不落库，证件号、UCI、申请号即使读到也不存
留记录不留原件每次问答存一条：问题、引用了哪几条内容、回答、模型、版本号。用来查错和改内容
便宜的先上Gemini Flash 或 Claude Haiku，一问几分钱以内。我有 Google AI Pro，AI Studio 的 key 可以给你。模型键放服务端，页面不碰
用户能全删删账号就是清空这个人所有表，包括问答记录。你 README 第 3 条那个缺口，就在这里补

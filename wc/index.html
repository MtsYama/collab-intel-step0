先做：Circle 社区运营工具，Superlinear 第一个用

Circle 是社区平台，像 Discord 加会员系统，很多做课程和会员的创作者在上面开社区。我在运营的这个社区每个月有三件事靠人手：分佣对账（拉本月交易、按渠道算各家该得多少、出对账消息、回写台账）、证书发放（学员申请、模板合成、发放记录）、会员到期提醒（手动开的权限平台不会自动收回，几种权限各一套规则）。把这三件做成管理员自己点一下就能跑的工具。

技术任务书

管理员会做的四件事

  1. 接社区：填 Circle Admin API token，选权限组和渠道，五分钟接上
  2. 月结：点一下，拉本月交易，按渠道和分佣规则算出各家该得多少，生成对账消息，回写台账
  3. 发证书：学员申请进来，管理员核一眼，模板合成 PDF，发放并记录
  4. 收提醒：某个手动开的权限快到期、某笔付款权限已开但没进台账、某个成员标签和权限组对不上

数据长什么样

community   Circle token · 权限组 id 表 · 分佣规则 · 渠道表 · 通知去哪(Discord / 邮件 / 文案)
member      community_member.id ≠ user.id，两套 id 都存 · 权限组 · 标签 · 加入日 · 手动开的到期日
txn         Circle Transactions 导出 · 渠道归因 · 金额 · 币种 · 退款状态(退款 ≠ 取消订阅)
commission  月份 · 渠道 · 应付 · 已付 · 凭证 · 对账消息文本
cert        学员 · 课程 · 提出日期 · 模板 · PDF · 发放日
alert       类型(到期 / 权限漏 / 标签不符) · 对象 · 触发时间 · 是否处理

坑我踩过的：Circle 按 User-Agent 拦请求，默认 UA 直接 403，症状跟 token 失效一模一样；查会员身份只能看权限组不能看标签，直接付费的用户一个标签都没有；退款了不等于取消订阅，只看 refunded 不算完成；手动开的权限平台不会自动收回。

我怎么想的

起点是 SA 那个帖子，一个人一周做出 7.9 万人用的找玩具地图。我在国内让朋友代跑过两三家店找不到货，你在渥太华看到 Chiikawa 联名 MINISO Rideau 有、别处没有。这两件事是同一件事：限量的东西，谁知道哪家店此刻还有，谁就有价值。

你说得对，广义上做商业就是信息商，倒狗信息网也是信息商。区别只在两点：信息从哪来是不是干净的，钱从谁身上赚是不是体面的。这两点我会守住：数据靠用户打卡和官方公开信息，不爬不逆向；不做代抢，不做交易。

然后是钱。我查完的结论很干脆：这类东西没有一家靠情报本身收费活下来，品牌方一分钱不会给。所以第一年我不打算收钱，目标是攒一个真实用户群和一套跑通的引擎。这个群以后放什么品类都行，这才是资产。你练扩容和队列，我练产品和冷启动，两边都不亏。

做什么

一个「掉落地图」：什么东西、哪天开卖、哪家店此刻还有、推给想要的人。快餐联名玩具第一，卡牌第二，Pop Mart 第三。引擎一套，品类换数据。

在哪做

加拿大先，渥太华和多伦多起，麦当劳 + Tim Hortons + Starbucks + Wendy's。理由四条：不用审批，两周能上；咱俩走两条街就能验证；你的 Discord bot 直接用；加拿大零竞品，而且联名节奏跟美国错位，美国的日历对加拿大人没用。国内放第二阶段，我有个体户，备案我来办，等北美跑通一次再起。

不做什么

不爬小红书、Reddit、Facebook；不代抢；不做交易；不做城市活动站、餐馆站、华人资讯站；域名和站名不带品牌词；不问用户年龄。

钱

第一年不收钱。第二年订阅（一个月两三加元，提醒优先送、门店级实时库存）+ eBay 和 Amazon 联盟 + 广告。品牌方不会给分成，我认。

四周之内算不算成

跑一次真实联名活动。打卡 300 条以上，Discord 群 100 人以上，48 小时内回来看的人超过三成。成了就接卡牌；没成就换品类，引擎不扔。

给你的技术任务书

用户会做的四件事

  1. 打开看日历：这个月渥太华有什么联名，哪天开卖，规则是什么
  2. 点进一个联名，看地图：哪家店有人报告「还有」，几小时前报的
  3. 到店之后打卡：有 / 没有 / 限购几个，一键提交，可选拍张照
  4. 订阅：关注某个联名或某个城市，开卖前一天和有人打卡「有货」时收到提醒

数据长什么样

drop      什么 · 哪个牌子 · 开卖日 · 结束日 · 规则文本 · 款式列表 · 城市
store     OSM id · 牌子 · 坐标 · 地址 · 营业时间 · 城市
report    store · drop · 款式 · 有/无/限购 N · 时间戳 · 用户 · 照片(可选,不公开)
subscribe 用户 · drop 或 city · 渠道(discord / push / email)
alert     subscribe × report 触发,去重,合并成一条

打卡两小时后自动变灰，页面上永远显示「N 人 X 小时前报告」，不显示「有货」两个字。这是免责，也是你担心的「限量的东西 50 人打卡就废了」的答案：半衰期短才有人要提醒。

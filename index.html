上一版把 Circle 运营工具排第一，我自己看了一遍就否了：它绑着我现在的工作和立正，市场是几十家中文社区，本质是把我的服务打包，不是产品。「我天天在做」不等于「适合商业化」。这版换个问法：什么东西有人已经在为它花钱，我又正好比一般人懂，而且做出来是个软件不是个服务。

这次的标准

五条，按顺序过：已经有人在为这件事花钱，而且我说得出是谁、花多少；我比一般人懂，能判断对错，也有地方发；做出来是软件，用户自己用，不靠我盯；王聪有足够的技术活干；四周能验证，验证不靠我认识的人。

定了

先做：落地清单

给在加拿大的中国留学生和新移民，一套能勾选、能存进度、到期会提醒的行政清单。第一批三份，全是我走过的：学签续签和 IMM 5009 补发被退回怎么重交；毕业后 180 天内的 PGWP；TRV 和 SIN 的更新顺序。之后按到期时间铺开：报税、驾照、医保、开户、手机、回国前。

它跟我以前做的回国清单、IMM 5009 冲刺清单是一个东西，只是从「Claude 给我一个人生成」变成「用户自己选场景、自己走」。引擎在，内容在，缺的是多用户、提醒、支付，这三样是王聪的活。

为什么它过得了五条

钱：留学生本来就在为这些事花钱，问顾问、买攻略、交政府费用、错过期限重交。懂：我每一步都踩过坑，市面上的免费站是政府写的通稿，不会告诉你 IRCC 把补发件寄错地址之后怎么办。软件：用户自己勾自己走，我不用盯。王聪：清单引擎、提醒、账号、支付、页面变更监控，够干。验证：小红书发三份，收藏和私信数一周就有。

第二个：Claude Code 工作流工具

等落地清单跑起来就开，或者王聪如果对这个更有兴趣，可以同时起。我这套规则、记忆、hook 体系是真在用的，SA 的学员是现成用户，圈子今天就有几万星的热度。要先跟鸭哥把边界说清：他做 context infrastructure 那一层，我们做个人和小团队的治理工具。

不做什么

不做移民建议，不代办，只做信息和清单，因为收费给建议只有持牌顾问、律师、魁北克公证人能做。不存证件号。不做 Circle 工具，不做电气那条线的软件版，不做联动情报。

钱

清单免费看，付费的是「存进度 + 到期提醒 + 更新推送」，一年 C$19 到 29；清单包按场景卖 C$9；开户、手机、保险的新客联盟按成交。第一年目标：付费用户几百人，覆盖你我的时间。数字我没核，先这么定，跑一个月再改。

四周之内算不算成

三份清单上线；小红书三帖收藏合计过 500；打开清单的人过 300；付费或订阅提醒的过 50。四件成三件算成。不成就换第二个方向，引擎不扔。

用户会做的四件事

  1. 选场景：我是学签快到期 / 刚毕业要办 PGWP / 要更新 TRV 和 SIN / 第一次报税
  2. 走清单：一步一步勾，每步有官方链接、要准备的材料、常见的坑；进度存着，换设备还在
  3. 收提醒：到期前 60 天、30 天、7 天；官方规则变了也推
  4. 分享：把清单发给同学，对方打开是干净的一份

数据长什么样

scenario   场景 · 适用身份 · 版本号 · 最后核对日期
step       属于哪个场景 · 顺序 · 标题 · 说明 · 官方链接 · 材料 · 坑 · 预计耗时
progress   用户 · 场景 · 已勾的 step · 用户自填的日期(如学签到期日)
deadline   由用户日期算出 · 类型 · 到期日 · 提醒节点
watch      官方页面 URL · 上次哈希 · 变更时间 → 提醒我改内容
user       邮箱 · 语言 · 渠道偏好 · 付费状态。不存证件号、不存申请号

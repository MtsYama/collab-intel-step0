# 首轮方案调研与技术决策

核查日期：2026-09-10。方法：公开网页搜索与正文抓取；未登录试用、未测试服务、未询价。本文是桌面调研，不是完工声明。需求、协作安排及未提供的输入见 [协作提案](canada-checklist-collaboration.md)。

## 1. 已有产品：先验证差异化

| 候选 | 官方可见事实 | 对本项目的意义与未知 |
|---|---|---|
| [Welcome to Canada / PeaceGeeks](https://www.peacegeeks.org/welcome) | 免费、可信资源、个性化推荐、地区服务；不同省份语言覆盖不同，BC 列出简繁中文，多数内容可离线使用 | 是实质性的免费替代。个人行政期限提醒、版本化清单和付费需求本轮未验证，不能声称竞品没有 |
| [Canoo](https://canoo.ca/) | 定位是欢迎加拿大新移民的免费 App，文化场馆与会员优惠 | 属于相邻获客/新移民服务，不是已证实的学签/PGWP 清单替代；不能据此推断其 API 或合作可用 |
| [IRCC 免费安居服务](https://ircc.canada.ca/english/newcomers/services/index.asp) | 官方提供安居服务查找入口 | 内容可信度和免费服务是基线；资格有范围，不能说全部留学生均能使用全部服务 |
| 现有单文件引擎 + 用户自己的日历 | 仅任务书声称已有本地勾选和存进度，代码未提供 | “不做新系统”的真实对照：开发少，但不满足跨设备和自动规则更新；可以验证用户是否只需免费内容 |

推断：值得验证的不是“加拿大中文信息稀缺”，而是“具体手续的经过核对的步骤、版本变化解释和可靠提醒能否降低行动负担”。当前证据不足以判定有人愿意付 C$19–29。

Arrive 候选的 `arrivein.com` 抓取遇到 DNS 解析失败，排除本轮事实比较；这不是停运证据。本轮没有产品实际使用、合同、安全认证或用户访谈证据。

## 2. Build vs buy 与硬约束筛选

不买整个清单 SaaS，也不自己造认证和支付。自建差异化的清单内容模型、进度版本规则、日期提醒编排；采用成熟基础设施。

| 路线 | 功能/工程成本 | 预算与运行限制 | 迁移代价与结论 |
|---|---|---|---|
| [Softr](https://www.softr.io/pricing) 无代码门户 | 自带数据库、工作流及登录能力，具体清单 UI/退订需要试做 | 当前页面 Free 为 5 app users，Basic 客户用户额度也不足 50 人验证目标；更高档成本不匹配 USD 20。价格可能依赖账期，不据此计算未确认月账单 | 页面/工作流迁出需要重建；淘汰为主系统，可做匿名展示但不能偷换成完整 v0.1 |
| Cloudflare + Supabase Auth/Postgres | 托管认证、关系库减少部分认证运维；仍要自建清单、邮件和支付接入 | [Free](https://supabase.com/pricing) 含 500 MB 数据库、50k MAU，但不活跃项目一周后暂停；Pro 起价 USD 25，尚未加邮件已超预算 | Postgres 迁出相对直接，但授权策略和身份会话仍有迁移成本；作为预算放宽后的备选 |
| Cloudflare Workers + D1 + Better Auth | 业务模型可控，认证使用库；数据库迁移、会话安全、限流和邮件编排仍由项目维护 | [Workers](https://developers.cloudflare.com/workers/platform/pricing/) 可用免费档或付费基础档；[D1](https://developers.cloudflare.com/d1/platform/pricing/) 有免费额度，不是无限可用 | SQLite/JSON 数据可导出，D1 绑定、定时任务、认证记录需迁移；当前优先做本地可行性验证 |
| 不做新后端：现有网页 + 用户日历 | 最少工程量；引擎待提供 | 无新增邮件/认证服务成本，不能完成跨设备产品承诺 | 最易撤回；作为需求验证对照，不宣称完成 v0.1 |

没有采用数值加权：试用结果、实际复用成本和用户付费意愿未知，数字会制造精确的假象。技术参与方现已表示预计每周约 40 小时，但这不等于有效编码工时或交付保证；主导约束仍是预算、四周可交付性和提醒安全性。

## 3. 技术决策：进入本地验证，而非批准上线

推荐 Workers + D1，前端优先复用现有引擎；引擎看过之前不选新 UI 框架。认证优先 Better Auth 魔法链接，邮件 Resend，支付 Stripe Checkout 年订阅。

证据：Better Auth [1.5 官方发布说明](https://better-auth.com/blog/1-5) 明确原生接受 D1 binding；[magic-link 文档](https://www.better-auth.com/docs/plugins/magic-link) 提供插件流程。本轮未锁定依赖版本、未测试 Workers 运行兼容性，旧教程的 `d1Adapter()` 不能直接复制。此前猜测的 `/docs/adapters/d1` 返回 404，以上是搜索后核对的有效来源。

取舍：少一项独立数据库服务，也少一个免费项目休眠风险；但认证库不等于托管认证，我们承担会话、迁移、滥用防护和运行升级。既有云账号、区域选择和跨境数据处理均未核对，不声称符合全部隐私要求。

不能同时得到的东西：在当前预算和免费邮件配额下，无法承诺不限量且有送达保障的高峰提醒。付费权限、公开场景 ID、内容版本和删除策略一旦服务真实用户就不是随意可改的临时细节。

重新评估条件：D1/认证在本地运行或隔离测试失败；需要加拿大境内数据驻留而当前组合不能满足；邮件额度不足以按时提醒；已有引擎的运行约束明显不兼容；预算允许托管数据库且可降低维护负担。

## 4. 成本：真正的约束在邮件高峰

以下是规划情景，不是已产生账单。金额除标明 C$ 外均为 USD。

- Workers Free：0；Paid 最低每月 5，按量另计。[官方价格](https://developers.cloudflare.com/workers/platform/pricing/)
- D1 免费额度：每天读 500 万行、写 10 万行、总存储 5 GB；扫描行数并不等于返回行数，提醒应有日期/状态索引。超限可能导致请求失败。[官方价格](https://developers.cloudflare.com/d1/platform/pricing/)
- Resend Free：每月 3,000、每日 100 封；Pro 从每月 20 起。定价的动态页面提取不完整，额度结合官方定价搜索结果和[官方配额说明](https://resend.com/docs/knowledge-base/account-quotas-and-limits)核对，上线前重新确认。不能把“每人两分钱”当供应商单价。
- 假设 300 用户，每人当月两次登录、三个提醒：300 × 5 = 1,500 封/月，月量看似够，但同一天 300 人登录或到期就超过免费日量。合并、限流不能无限推迟关键提醒；要预留登录容量、监测积压，额度不足必须限制接入或调整预算，不能偷偷丢信。
- 免费计算 + 免费邮件固定服务费约 0；付费 Workers + 免费邮件约 5；付费 Workers + Resend Pro 约 25，已超硬约束。域名摊销、税费及其他按量费用另加，不能保证总额不超 20。
- [Stripe 加拿大价格](https://stripe.com/en-ca/pricing)：加拿大境内卡标准费率 2.9% + C$0.30；Billing 按用量模式另收账单额 0.7%。年订阅不能只算 Checkout 基础手续费。C$19 的示例费用约 C$0.98，C$29 约 C$1.34；不含国际卡、汇兑、税务服务、退款争议等，商户所在地尚待确认。

每月 20 的硬预算不是云端自动截断账单保证。实现需设置应用侧配额和告警，额度接近阈值时限制新接入；不能自动升级付费档，也不能牺牲已经承诺的提醒而无提示。

## 5. 内容与合规风险

[IRCC PGWP 申请页](https://www.canada.ca/en/immigration-refugees-citizenship/services/study-canada/work/after-graduation/apply.html) 确认最多毕业后 180 天申请，并有学签已过期、恢复身份及等待期间工作资格的额外条件。该页面中的费用和“180 天”不是完整资格判断。日期触发点、有效身份、材料、语言/专业要求、人在境内/境外须逐场景核对；v0.1 不根据毕业日期直接给法律结论。

[CRTC 指引](https://crtc.gc.ca/eng/com500/guide.htm)及 [FAQ](https://crtc.gc.ca/eng/com500/faq500.htm) 的官方搜索结果确认商业电子消息涉及同意、发送者身份和退订要求。FAQ 正文抓取返回 403，未完成逐条适用性核查。提醒、产品更新和推广不可混为同一种邮件；最终消息分类、地址披露、同意记录保留和隐私政策需负责人审查。本报告不是法律意见，也不因写了免责脚注就宣称合规。
